# Textify
A modern Python Tkinter-based GUI application for text manipulation, featuring uppercase, lowercase, reverse, word count, palindrome checker, find &amp; replace, and more.
✨ Textify – Smart Text Manipulation Tool

Textify is a modern Python GUI application built using Tkinter. It provides useful text manipulation features with a clean and user-friendly interface.

🚀 Features
Uppercase & Lowercase Conversion
Reverse Text
String Length Checker
Word Counter
Title Case Converter
Vowels & Consonants Counter
Palindrome Checker
Remove Extra Spaces
Remove Duplicate Characters
Character Frequency Counter
Update Word
Combine Words
Find & Replace
Copy Result
Save Result as TXT
Clear All
🛠️ Technologies Used
Python
Tkinter
Collections Module
📦 Installation
Clone the repository:
bash
git clone Textify

Open the project folder:
bash
cd Textify

Run the application:
